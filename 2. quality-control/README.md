# Контроль качества

## Условие задачи

На складе хранятся контейнеры с товарами, каждому из которых присвоен номер. Четный номер означает, что контейнер прошел проверку качества. Ваша задача — найти номер последнего проверенного контейнера (последнего четного числа в массиве). Если в массиве нет четных чисел, вернуть `-1`.

## Формат входных данных

- В первой строке задаётся число `N` — размер массива (количество контейнеров).
- Во второй строке вводится массив из `N` целых чисел, разделённых пробелами.

## Формат выходных данных

Программа должна вывести одно число — номер последнего проверенного контейнера (последнее чётное число). Если чётных чисел нет, вывести `-1`.

## Пример

**Входные данные:**
```text
9
7 3 4 1 10 11 12 19 21
```

**Выходные данные:**
```text
12
```

## Решение

Решение написано на языке **Go (Golang)** и использует линейный проход по массиву для поиска последнего четного числа.

### 1. Быстрый ввод-вывод (Fast I/O)

Для чтения данных используется обертка `IO` с `bufio.Scanner` (разбивая ввод по словам) и `bufio.Writer`. Это обеспечивает высокую скорость работы программы, что особенно важно при обработке больших массивов данных.

### 2. Логика решения (QualityControl)

Алгоритм крайне прост и эффективен:
1. Изначально переменная `prev` (предыдущее найденное четное число) инициализируется значением `-1`. Это значение будет возвращено по умолчанию, если четных чисел в массиве не окажется.
2. Программа проходит по массиву один раз (цикл `for _, v := range nums`).
3. На каждой итерации проверяется, является ли текущее число четным (`v % 2 == 0`).
4. Если число четное, переменная `prev` перезаписывается текущим значением `v`. 
5. Поскольку мы идем слева направо, в `prev` в итоге останется **последнее** встреченное четное число.
6. В конце функция возвращает `prev`.

### 3. Сложность алгоритма

* **Время (Time Complexity): O(N)**, где `N` — количество элементов в массиве. Мы проходим по массиву ровно один раз. Это оптимальное время для данной задачи, так как в худшем случае нам нужно посмотреть на каждый элемент, чтобы убедиться, что он не последний четный.
* **Память (Space Complexity): O(1)**. Алгоритм использует только одну дополнительную переменную (`prev`) для хранения результата, не выделяя дополнительную память пропорционально размеру массива.
