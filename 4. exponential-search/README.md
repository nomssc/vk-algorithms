# Экспоненциальный поиск (Exponential Search)

## Условие задачи

Дан отсортированный по возрастанию массив целых чисел и некоторое целое число. Ваша задача — найти минимальный диапазон индексов (подмассив), в котором может находиться заданное число. Используйте метод экспоненциального поиска.

## Формат входных данных

- В первой строке задаётся число `N` — количество элементов в массиве.
- Во второй строке вводится массив из `N` целых чисел, разделённых пробелами.
- В третьей строке задаётся целое число `target`, для которого нужно найти диапазон.

## Формат выходных данных

Программа должна вывести два числа через пробел, представляющие диапазон индексов, где может находиться число `target`. 
Если число находится в массиве, это должен быть диапазон, содержащий индекс числа. Если число отсутствует, диапазон должен содержать индексы, где оно могло бы быть вставлено.

## Пример

**Входные данные:**
```text
11
8 11 12 16 18 21 33 36 48 54 63
16
```

**Выходные данные:**
```text
2 4
```

*Пояснение: число 16 находится в подмассиве от индекса 2 до индекса 4.*

## Решение

Решение написано на языке **Go (Golang)** и реализует алгоритм **Экспоненциального (галопирующего) поиска**.

### 1. Быстрый ввод-вывод (Fast I/O)

Используется стандартная для ваших решений обертка `IO` на базе `bufio`. Это гарантирует, что чтение трех строк входных данных и вывод результата будут максимально быстрыми.

### 2. Логика решения (Exponential Search)

Экспоненциальный поиск идеально подходит для нахождения границ в отсортированных массивах. Алгоритм работает в два этапа:
1. **Обработка крайних случаев:**
   * Если массив пуст (`n == 0`), возвращается `[-1, -1]`.
   * Если самый первый элемент больше искомого (`nums[0] > target`), то искомого числа точно нет в массиве (так как он отсортирован), и его место вставки — в самом начале. Функция возвращает `[0, 0]`.
2. **Поиск диапазона (Галопирование):** 
   * Переменная `i` начинает с `1` и удваивается на каждой итерации (`1, 2, 4, 8...`).
   * Цикл продолжается до тех пор, пока `i` не выйдет за пределы массива или элемент `nums[i]` не станет строго больше `target`.
3. **Формирование границ:**
   * Если индекс `i` "улетел" за пределы массива (`i >= n`), значит, `target` находится в правой половине. Возвращается диапазон от `i/2` (последний проверенный индекс) до `n-1` (конец массива).
   * В противном случае `target` зажат между индексами `i/2` и `i`. Возвращается этот диапазон.

### 3. Сложность алгоритма

* **Время (Time Complexity): O(log N)**. Нам не нужно проходить весь массив. Количество итераций цикла пропорционально логарифму от позиции искомого элемента.
* **Память (Space Complexity): O(1)**. Алгоритм использует только несколько переменных для хранения индексов и не требует выделения дополнительной памяти (кроме возвращаемого среза из двух элементов).
