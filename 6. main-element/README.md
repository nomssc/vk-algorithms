# Элемент большинства (Majority Element)

## Условие задачи

Дан массив целых чисел. Ваша задача — определить, существует ли элемент, который встречается больше половины раз в массиве. 

Если такой элемент существует, вернуть его. Если такого элемента нет, вернуть `-1`.

## Формат входных данных

- В первой строке задаётся число `N` — размер массива (количество элементов).
- Во второй строке вводится массив из `N` целых чисел, разделённых пробелами.

## Формат выходных данных

Программа должна вывести:
- элемент массива, который встречается больше половины раз;
- `-1`, если такого элемента нет.

## Пример

**Входные данные:**
```text
7
7 7 8 8 8 8 9
```

**Выходные данные:**
```text
8
```

## Решение

Решение написано на языке **Go (Golang)** и использует классический подход с подсчетом частот.

### 1. Быстрый ввод-вывод (Fast I/O)
2. 
В коде реализована обертка `IO` над `bufio.Scanner` и `bufio.Writer`. 
Использование `bufio` с методом `ScanWords` позволяет читать данные намного быстрее, чем стандартные функции `fmt.Scan` или `fmt.Println`. Это критически важно в олимпиадном программировании для предотвращения ошибок **Time Limit Exceeded (TLE)** на больших тестах.

### 2. Логика решения (Map / Hash Table)
3. 
Основная логика находится в функции `MainElement`:
1. Создается хеш-таблица (словарь) `seen`, где ключом является само число из массива, а значением — количество его вхождений.
2. Программа один раз проходит по массиву, заполняя эту таблицу.
3. Затем происходит проход по таблице: если счетчик какого-либо элемента строго больше `n/2`, этот элемент сразу возвращается.
4. Если после проверки всех элементов подходящего не нашлось, возвращается `-1`.

### 3. Сложность алгоритма

* **Время (Time Complexity): O(N)**, где N — количество элементов в массиве. Мы проходим по массиву один раз (O(N)), а затем по хеш-таблице (максимум O(N) уникальных элементов). В итоге получаем линейное время.
* **Память (Space Complexity): O(N)**. В худшем случае (если все элементы в массиве разные) хеш-таблица сохранит N пар «ключ-значение», что потребует O(N) дополнительной памяти.
